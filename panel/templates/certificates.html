How to set up a Windows laptop by hand
  1. Download RADIUS-Root-CA.cer (section 2) and the test .pfx above, and copy both to the laptop.
  2. Double-click RADIUS-Root-CA.cer → Install Certificate → Local Machine → Place in Trusted Root Certification Authorities.
  3. Double-click the .pfx → Current User → enter its password → Automatically select the store.
  4. Control Panel → Network and Sharing Center → Set up a new connection → Manually connect to a wireless network: Network name {{ ssid }}, Security WPA2-Enterprise, Encryption AES → Next → Change connection settings.
  5. Security tab → method Microsoft: Smart Card or other certificate → Settings: Use a certificate on this computer; tick Verify the server's identity; Connect to these servers: {{ s.server_name }}; Trusted Root: tick {{ root.subject if root else 'the RADIUS root' }} → OK.
  6. Advanced settings → 802.1X → tick Specify authentication mode → User authentication → OK.
  7. Connect to {{ ssid }}. If Windows asks which certificate, pick the test one. It must not ask for a password.

Before installing Intune profiles on this laptop later, delete this manual Wi-Fi network and the test certificate (certmgr.msc → Personal).

How to set up a Mac (or iPhone / iPad)
  1. Download the .mobileconfig above and open it on the Mac (AirDrop or email it to an iPhone).
  2. macOS: System Settings → General → Device Management (older macOS: Privacy & Security → Profiles) → double-click the downloaded profile → Install. iPhone: Settings → Profile Downloaded → Install.
  3. Enter the .pfx password you chose when asked, then your Mac login password. The profile shows "Unverified": that is expected for a test profile.
  4. Choose {{ ssid }} from the Wi-Fi menu. It connects with no username or password. If macOS asks which certificate to use, pick the TEST one.
  5. Remove after testing: Device Management → select the profile → − (minus). This deletes the certificate and the network.
