Windows

  1. Open the downloaded Install-WiFi-….cmd. If Windows says "Windows protected your PC", click More info → Run anyway.
  2. Click Yes on the admin prompt.
  3. Wait for Done, then press a key. The laptop connects to {{ ssid }} by itself.

Needs admin rights on the laptop (installs for the whole computer, so it also works before anyone signs in).

Mac

  1. Open the downloaded WiFi-….mobileconfig.
  2. Go to System Settings → General → Device Management (older macOS: Privacy & Security → Profiles), double-click the profile, then click Install.
  3. Enter your Mac password. {{ ssid }} connects by itself.

iPhone / iPad: Settings → Profile Downloaded → Install.
