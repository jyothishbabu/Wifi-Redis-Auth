Aruba config for {{ o.name }}

On that office's AP-635 virtual controller: ssh admin@<VC-IP>, then configure terminal, then paste. Replace the two <…> values. This page shows the office's RADIUS secret, so don't share a screenshot of it.

! {{ ssid }} - Aruba Instant virtual controller config for {{ o.name }}

! 1. Virtual controller IP (needed by dynamic-radius-proxy). Skip if already set.
virtual-controller-ip <VC-IP>

! 2. Send all RADIUS from the VC IP (this office is allowed from {{ o.ips|join(', ') }})
dynamic-radius-proxy

! 3. RADIUS server in AWS
wlan auth-server RADIUS-AWS
  ip {{ s.panel_host or '' }}
  port 1812
  acctport 1813
  key {{ o.secret }}
  nas-id {{ o.name }}
  timeout 10
  retry-count 3
  exit

! 4. Access rule (same name as the SSID)
wlan access-rule {{ ssid }}
  rule any any match any any any permit
  exit

! 5. The SSID
wlan ssid-profile {{ ssid }}
  enable
  type employee
  essid {{ ssid }}
  opmode wpa2-aes
  vlan <STAFF-VLAN-ID>
  auth-server RADIUS-AWS
  radius-accounting
  radius-accounting-mode user-association
  rf-band all
  dtim-period 1
  broadcast-filter arp
  dot11k
  dot11v
  max-authentication-failures 0
  exit

commit apply
